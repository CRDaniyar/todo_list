Команды
2 /add <текст> - добавить задачу
/list показать список всех задач
/done <номер> - отметить задачу как выполненную
/delete <номер> - удалить задачу
/quit - - завершить работу клиента

3 Сервер принимает подключение accept() в основном цикле и передает обработку каждого клиента в отдельный поток (thread.Threading). Благодаря этому реализована одновременная работа клиентов

4 Список задача tasks находится на сервере в едином экземляре. Для предотвращения race condition используется threading.Lock()
